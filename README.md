# My Visit Card
Личная визитная карточка frontend-разработчика — одностраничный сайт-портфолио с анимациями и интерактивными эффектами.
## О проекте
Сайт собран на чистом HTML, CSS и JavaScript без сборщика. Включает:
- **Hero** — параллакс-слои и эффект дождя
- **About** — частицы, глитч-фото, анимированный терминал
- **Portfolio** — карточки проектов с модальным окном и слайдером
- **Contact** — форма обратной связи
- **Preloader** — 3D-логотип на Three.js
## Стек
HTML · CSS · JavaScript · GSAP · Swiper · Three.js
## Запуск
Клонируйте репозиторий и откройте `index.html` в браузере или запустите локальный сервер:
```bash
git clone https://github.com/404KISTAVUCHKA/My-Visit-Card.git
cd My-Visit-Card
npx serve .
```
> Для корректной работы ES-модулей (Three.js) рекомендуется локальный сервер, а не открытие файла напрямую.

## Структура
```
├── index.html          # разметка и данные проектов
├── index.css           # точка входа стилей
├── css/                # Base + секции
├── js/                 # скрипты (параллакс, глитч, модалка и др.)
└── img/                # изображения и favicon
```
